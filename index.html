Glossary with definitions and examples

line
A mark that shows edge or direction.
Example: Contour lines define an object.
tone
Lightness and darkness.
Example: Tonal shading makes an object look 3D.
proportion
Relative size of parts.
Example: Large eyes can distort portrait proportion.

pulse
The steady beat in music.
Example: A class claps the pulse together.
tempo
Speed of the music.
Example: Allegro is a fast tempo.
ostinato
A repeated musical pattern.
Example: A bass ostinato repeats underneath a melody.
